# 📚 Control readmes

Each control, service and helper in the Atc.Wpf libraries can have its own readme next to its source code. The same readmes are shown in the **Readme** tab of the sample application. This section collects them, grouped by library and folder:

| Library | Contents |
|---|---|
| [Atc.Wpf](../../src/Atc.Wpf/README.md) | Core: MVVM helpers, layouts, value converters, media, drag and drop |
| [Atc.Wpf.Controls](../../src/Atc.Wpf.Controls/README.md) | Atomic controls: inputs, buttons, colors, selectors, data display, layouts, zoom |
| [Atc.Wpf.Forms](../../src/Atc.Wpf.Forms/Readme.md) | `Label*` form fields with label, validation and mandatory marker |
| [Atc.Wpf.Components](../../src/Atc.Wpf.Components/README.md) | Dialogs, viewers, monitoring, notifications, flyouts and other composite components |
| [Atc.Wpf.FontIcons](../../src/Atc.Wpf.FontIcons/README.md) | Font-based icons |
| [Atc.Wpf.Theming](../../src/Atc.Wpf.Theming/README.md) | Light, Dark and high-contrast theming, `NiceWindow` |
| [Atc.Wpf.Network](../../src/Atc.Wpf.Network/Readme.md) | Network scanning and discovery |
| [Atc.Wpf.Hardware](../../src/Atc.Wpf.Hardware/Readme.md) | Hardware, system and inspection pickers |
| [Atc.Wpf.UndoRedo](../../src/Atc.Wpf.UndoRedo/Readme.md) | Undo/redo history view and keyboard behavior |

Use the navigation on the left to open a readme. The API reference for every type is under [API Reference](../api/Atc.Wpf.yml).
